Папки backup и export показываются целиком, со всеми вложенными каталогами; файлы выгрузок (.dt/.cf) можно скачать по ссылке. Файл, загруженный для импорта, остаётся в backup с исходным именем без изменений.

Окно клиента откроется на вашем рабочем столе. Для получения лицензии запустите клиент, получите её в окне 1С, затем нажмите «Перенести полученные лицензии». Сетевой ключ NetHASP настраивается в 1c-client/.env (NETHASP_ADDRS).

Обновление Docker-образов

Загружает обновления базовых образов, пересобирает локальные образы из текущих Dockerfile и пересоздаёт контейнеры. Данные PostgreSQL и 1С в именованных Docker volumes сохраняются.
