Обновление Docker-образов

Загружает обновления базовых образов, пересобирает локальные образы из текущих Dockerfile и пересоздаёт контейнеры. Данные PostgreSQL и 1С в именованных Docker volumes сохраняются.

Настройки проекта

Управляйте параметрами сервера 1С, PostgreSQL и клиентского приложения в одном месте. Все изменения сохраняются в соответствующие файлы .env.

Загружаю настройки…
Изменения вступят в силу после применения конфигурации.
ⓘ
Обратите внимание. После изменения каталога резервных копий обязательно пересоздайте контейнер onec-server, иначе он продолжит использовать старую папку. Для этого сохраните настройки и обновите/пересоздайте контейнер. Изменение версии 1С или базового образа может потребовать пересборки образов. Пароль PostgreSQL не отображается: пустое поле сохраняет прежнее значение.

Распределение оперативной памяти

    

      
▦
SERVER_MEMORY_LIMIT · 0 — без лимита

      
▤
POSTGRES_MEMORY_LIMIT · 0 — без лимита

      
▣
CLIENT_MEMORY_LIMIT · 0 — без лимита

    

    
Это верхние лимиты Docker, а не заранее зарезервированная память. Фактическое потребление зависит от нагрузки. Для пользователей ограничивается общий клиентский контейнер, а не каждый пользователь отдельно.

    

    
Установщики загружаются в server/dist и postgres/dist. Если папки не выбраны, используются уже имеющиеся файлы.
